# Внешняя торговля Республики Беларусь 2000–2021

Анализ экспорта и импорта важнейших видов продукции по данным Национального статистического комитета Республики Беларусь.

##  Интерактивный дашборд

 **[Открыть дашборд в Yandex DataLens](https://datalens.yandex/t0k90kcao6doc?_share_link=public)**

## Что внутри

Дашборд состоит из 5 вкладок: **Обзор**, **Экспорт**, **Импорт**, **Зависимости и аномалии**, **Выводы**. На каждой вкладке — графики, диаграммы и текстовые комментарии с ключевыми выводами.

## Данные

- **Источник:** Национальный статистический комитет Республики Беларусь.
- **Период:** 2000–2021.
- **Позиции:** 13 товаров в импорте, 19 — в экспорте.
- **Единицы:** тыс. т, тыс. м³, тыс. шт., тонн, штук, млн USD.

## Структура репозитория

- `data/raw/` — исходные файлы `.xlsx`
- `data/processed/trade_long.csv` — обработанные данные в длинном формате
- `scripts/prepare_data.py` — скрипт подготовки данных
- `docs/screenshots/` — скриншоты дашборда
